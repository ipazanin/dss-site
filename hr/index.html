Projekti

Kuna

Financijska aplikacija za malu tvrtku koja radi u potpunosti u pregledniku. Sinkronizira bankovne izvode, izrađuje račune, čita PDV prijave i platne liste od knjigovođe te prati kredite i ulaganja. Knjige su jedna datoteka na vlasnikovom Google Driveu, bez backenda.

Vue 3, TypeScript, Google Drive i Gmail API
Otvori aplikaciju Izvorni kod

Tipsy Trouble

Kartaška igra za društvo na jednom zajedničkom mobitelu ili više povezanih. Ima vlastite karte, privremena pravila s odbrojavanjem i pravila koja piše sam stol, a nakon prvog posjeta radi i bez interneta.

Vue 3, TypeScript, IndexedDB, service worker
Igraj Izvorni kod

Shunt

Nadzorna ploča koja preko Bluetootha, izravno iz preglednika, čita JK-BMS i Victron solarni regulator. Iz razlike njihovih struja dobiva se potrošnja broda bez ugradnje shunta.

Vue 3, TypeScript, Web Bluetooth
Otvori aplikaciju Izvorni kod

Valore

Privatni pregled portfelja i neto imovine. Računi, dionice, nekretnine i dugovi ostaju u pregledniku, uz grafove kroz vrijeme i JSON sigurnosne kopije.

Vue 3, TypeScript, Pinia, Dexie, Chart.js
Otvori aplikaciju Izvorni kod

Espresso

Hrvatski agregator vijesti koji sam pokrenuo 2020. ASP.NET backend čita RSS izvore izdavača za iOS i Android aplikacije, React web aplikaciju i Blazor administraciju. Dosegao je oko 800 dnevno aktivnih korisnika.

ASP.NET, C#, Blazor, React, PostgreSQL
